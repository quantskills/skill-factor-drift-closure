# v2 文档重写说明

## 为什么重写

旧版文档把大量验收条目、数值和历史说明连续堆在一起，证据很多，但读者不容易先回答三个基本问题：项目为什么做、解决了什么、结果意味着什么。

## 本次改法

新版统一按以下顺序组织：

1. 项目目的；
2. 项目解决的问题；
3. 研究设计和时间边界；
4. 关键结果；
5. 结果分析；
6. 统计可靠性、成本和敏感性；
7. 研究决策与不能声称的内容；
8. 复现命令和证据索引。

`README.md` 是短版入口，`report.md` 是完整研究叙事，`dashboard.html` 是快速浏览页面，`TASK_CHECKLIST.md` 保留为审计清单。数值、实验逻辑和上游技能源码不变，仅改变呈现方式和解释顺序。

## 研究结论口径

动态重训或换信号存在方向性改善，但没有通过 BH/Reality Check，也没有稳定超过固定半仓。因此文档不把单个策略的最高净收益写成已证实的最优策略，最终建议保留诊断和纸面验证，暂不自动下单。

后续新增的一周标签实验单独放在 `results/v3_one_week/`：标签改为 `open(t+2)/open(t+1)-1`，成熟度仍为 5 个周度观测；v2 四周标签结果继续作为权威基线，避免不同持有期混在同一结果目录中。
