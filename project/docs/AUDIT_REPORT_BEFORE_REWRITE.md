## 当前结论

已完成项目内技能→成熟标签监控→降权/重训/换信号→成本扣除→误报/恢复→统计审计的闭环。两个监控 CLI 和每个主实验重训 CLI 均保留真实运行记录。

评估仅保留有成熟日历的完整 4 相位样本：20250103—20260911，每相位 22 个四周持有期。收益为四个独立相位账户最终收益的算术平均；并非同步实盘组合净值。为保持相位期数一致，成熟但不足整组的末端日期同样排除，具体原因分列在backtest_audit.json。

18 个对照中，保守 BH 最小 p=0.4259，BH≤0.10 的数量为 0。循环块 Reality Check 正向 p=0.5403、负向 p=0.2731。不以个别方向性收益宣称闭环已获证明。

数据与规则限制：个股缺失标签改变填补假设后会明显改变绝对收益；健康参数扰动下告警占比从28.1%到100.0%，稳定性未通过。保留诊断用途，不自动执行健康监控给出的降权建议。

## 修正档案与适用边界

1. 阈值校准只取20240105—20241227，共51个成熟监控观测；修正阈值=0.05130806。旧脚本误将2025纳入2024校准。
2. 标签实际持有4周，在第5个周度观测才成熟；修正原‘5周持有’表述。末端未知收益不再填0冒充已评估收益。
3. 买卖成本、权重漂移、初始净值回撤、多重比较统计量、右删失与未暴露事件均已修正。所有旧收益数字失去当前验收地位。
4. 输入54列已经是上游导出的处理后因子值；所谓等权是这些导出列的直接均值，不是未处理原始行情因子的均值。
5. 2026样本已经被旧研究反复观察。即使代码只用2024校准，也不能把本次迭代包装为完全未见的确认性检验。下一步需新时间段或真正封存的样本。
6. 收益继承上游周度open(t+5)/open(t+1)定义，与真实日历上的下一交易日开盘成交未重新逐笔对齐；入场涨停/停牌过滤含下一交易日可成交信息，属于条件成交回测假设。融券是否可得、退出是否可成交及价格冲击未完全建模。
7. 少量个股标签缺失基准填0并计数；missing_return_sensitivity.json额外报告缺失收益=-100%的敏感性。对冲端该情景并非严格组合最坏界，不能称压力测试通过。
8. QuantStudio来源技能CLI与本地项目技能已执行并留痕，但GUI注册/平台任务提交尚未验证。单人申报去重也不能仅靠本地README证明。
